# Banking Website

## Giới thiệu

Đây là dự án website ngân hàng được xây dựng bằng ReactJS và Vite. Website cung cấp các chức năng cơ bản như quản lý tài khoản, giao dịch, và tra cứu thông tin khách hàng. Dự án hướng tới việc mô phỏng các nghiệp vụ ngân hàng cơ bản với giao diện thân thiện, dễ sử dụng.

## Hướng dẫn cài đặt và sử dụng

### 1. Cài đặt

- Yêu cầu: Node.js >= 14, npm hoặc yarn
- Clone repository về máy:
  ```
  git clone <repository-url>
  ```
- Cài đặt các package cần thiết:
  ```
  npm install
  ```
  hoặc
  ```
  yarn install
  ```

### 2. Chạy ứng dụng

- Khởi động server phát triển:
  ```
  npm run dev
  ```
  hoặc
  ```
  yarn dev
  ```
- Truy cập website tại địa chỉ: [http://localhost:5173](http://localhost:5173)

### 3. Build cho production

```
npm run build
```
hoặc
```
yarn build
```

## Vai trò các thành viên

- **Lâm Ngọc Tú**: Phát triển giao diện người dùng (UI/UX), xây dựng các component React và xây dựng giao diện HomePage.
- **Nguyễn Nam Hưng**: Xây dựng giao diện trang About, Login và SignIn.
- **Trần Trí Duy**: Xây dựng giao diện trang Careers và Security.
